## Overview

Python Step by Step is a browser-based beginner learning project with structured lessons, practice exercises, and interactive questions.

## Highlights

- Learn fundamental Python concepts through short lessons.
- Practice with multiple-choice and other interactive exercises.
- Navigate lesson topics from a course-style interface.
- Use available appearance and progress controls in the browser.

## Get started

Open [`index.html`](./index.html) in a compatible browser to explore the source application. This is a web project; an installer is not supplied by GitHub Releases here.

> **Compatibility:** The HTML learning materials are included as source. This repository does not currently publish a desktop installer or Android APK as a GitHub Release.
